# 🏋️‍♂️ Gym Management System

A full-stack Web Application designed for managing gym memberships, trainer assignments, session schedules, and member bookings efficiently. Built using **ASP.NET Core MVC** following a clean, maintainable, and scalable architecture.

---

## 🏗️ Architecture & Design Patterns

The project is structured using a **3-Tier Architecture**:
* **Presentation Layer (`GymManagementSystem.PL`):** ASP.NET Core MVC views and UI controllers.
* **Business Logic Layer (`GymManagementSystem.BLL`):** Handles core business logic, validations, and services.
* **Data Access Layer (`GymManagementSystem.DAL`):** Manages database access using Entity Framework Core.

### Design Patterns Used:
* **Repository Pattern:** For abstracts and encapsulates data access logic.
* **Dependency Injection (DI):** For loose coupling and better testability.

---

## 🛠️ Tech Stack & Tools

* **Backend:** C#, .NET / ASP.NET Core MVC
* **ORM:** Entity Framework Core
* **Database:** SQL Server
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
* **Libraries:** AutoMapper

---

## ✨ Key Features

* 👥 **Member Management:** Register, update, and manage gym members.
* 🏋️ **Trainer Management:** Track gym trainers and their assignments.
* 📅 **Session Scheduling:** Create and manage training sessions and schedules.
* 🎟️ **Booking System:** Book members into specific training sessions.
